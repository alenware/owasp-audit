# tienda-api

API de la tienda online: registro, login, catálogo, pedidos y administración de usuarios.

- `npm start` arranca en el puerto 3000.
- `npm test` ejecuta los tests con Jest.

Clientes: la web y la app móvil. Los pedidos incluyen la dirección de envío del cliente. Los pagos los gestiona un proveedor externo.
